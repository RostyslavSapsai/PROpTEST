# Діагностика COM5

## Встановлені факти

- Windows визначає COM5 як Arduino Uno, USB VID_2341/PID_0043. COM3/COM4 — Bluetooth.
- Порт відкривається. На P + newline при 115200 бод відповіді не отримано з DTR false та true; додаткова перевірка 9600 також без відповіді.
- Завантажувач Arduino відповів AVRDUDE. Зчитано всі 32768 байтів flash у artifacts/hardware-diagnostics/uno-before.bin.
- SHA256: DD3DAB54DABF3C53D53541A42E2D4E13A1FFADD928426FF1DD35DBE9D55F323C.
- У бінарному образі відсутня послідовність ASCII PT:1.0. В оглянутому D:/PT/PropTEST/PropTEST/firmware/PropTest.ino відповідь є літералом Serial.println("PT:1.0"). Це свідчить, що на платі не та прошивка, під яку написано адаптер.
- У старому shared/PropTest.Core/Serial/AutoConnect.cs ProbeAsync повертає Legacy навіть без handshake і без підтвердженої телеметрії. Тому статус підключення старої програми сам по собі не доводить сумісність з новими командами.

## Як читали

Офіційний AVRDUDE 8.2 (портативний інструмент у artifacts/hardware-diagnostics/tools) використано з явним читанням flash, забороною запису і автоматичного стирання:

```
avrdude -p atmega328p -c arduino -P COM5 -b 115200 -n -D -N -U flash:r:uno-before.bin:r
```

Лог: artifacts/hardware-diagnostics/read-flash.log, код завершення 0. Команди програмування, стирання, зміни EEPROM/fuses не виконувалися.
Відкриття порту та доступ до bootloader можуть перезапускати контролер. Команд запуску мотора не надсилали.
Опис r, -n і -D: https://avrdudes.github.io/avrdude/7.3/avrdude_4.html
Джерело інструмента: https://github.com/avrdudes/avrdude/releases/tag/v8.2

## Що виправлено у v0.6

Виявлення Arduino за USB замість першого COM; Bluetooth не перевіряється автоматично.
При запуску програми та при появі плати — автоматична спроба handshake без запуску запису.
В експерименті видно окремо USB-виявлення та підтвердження готовності прошивки.
Після невдачі спроби не повторюються нескінченно. Ручне відключення не скасовується автоматично.
Handshake приймає пробіли та різний регістр, як стара програма.
Мовчазний порт не позначається сумісним Legacy.

## Що залишилось

Повне керування на цьому стенді ще не відновлене. Потрібно узгодити прошивку на платі з протоколом програми або встановити точний протокол наявної прошивки.
Зчитаний binary не є вихідним Arduino-скетчем. Наявність чи відсутність ручних W:/M: команд у цьому образі окремо не встановлена.
Не можна автоматично підмінити його оглянутим прототипним .ino: калібрування й поведінка того коду не перевірені.
Фізичну працездатність датчиків та зупинку ESC ці перевірки не доводять.
