## Свідчення перевірок

Локальний звіт `docs/STATUS.md` для v0.14 містить успішні build, publish, smoke-запуск та 43 програмні випадки. Це зафіксовані попередні результати, а не новий запуск тестів у межах публікації документації.

Попередні звіти описують прошивання Uno PT:2.2, запис на нульовому газі й короткі навантажені проби попередніх PT:2.x. Власник також повідомляв про роботу стенда. Немає підстав переносити ці результати на ESP32-S3, новий ESC, новий датчик або чотири мотори.

Аварійний контроль тяги перевірявся підставленими даними; фізична аварія не відтворювалася. Під час підготовки цієї документації мотор не запускався й плата не прошивалася.

## Відомі проблеми та технічний борг

- Відсутня незалежно підтверджена точність тяги, струму та акустичних вимірювань.
- Поточний симулятор не моделює фізичну безпеку та повний силовий тракт.
- Виміри XYZ можуть пропускати швидкі коливання; спектрального аналізу немає.
- Час на ПК є часом приймання, а не синхронізованим часом усіх датчиків.
- Збереження відкриває SQLite-з'єднання для кожного виміру; UI отримує копії накопичених вибірок. Тривалі тести потребують вимірювання витрат пам'яті й продуктивності.
- Автовиявлення у Windows орієнтоване на Arduino VID. ESP32/USB-UART потребуватиме окремої перевірки виявлення.
- Linux, тривала безперервна робота та всі варіанти DPI не перевірені.
- Код актуального Engineering checkout ще не опублікований разом із цим пакетом; публічний репозиторій не відтворює v0.14 самостійно.
