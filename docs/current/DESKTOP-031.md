# PROpTEST Desktop 0.3.1

Основний інтерфейс — Windows-програма. Браузерний інтерфейс більше не розвиваємо; наявна прошивка S3-Connect 0.3.0 та її HTTP API залишаються без змін.

## Запуск і підключення

Запустити `START-v2.cmd` або `artifacts/windows-v2-desktop-031/PropTest.Desktop.exe`. Для перенесення потрібна вся папка з EXE.

На вкладці «Підключення»:

1. **Спосіб підключення** — USB або Wi-Fi. Для USB збережено автоматичне визначення плати. Для Wi-Fi ввести IP/ім’я ESP32 й натиснути «Перевірити з’єднання»; ноутбук залишається у звичайній мережі.
2. **Підключити плату до роутера** — одноразове налаштування через USB, розгортається окремо.
3. **Адреса та доступ до плати** — сіра картка з IP, власною мережею та паролем плати. Пароль можна скопіювати. Він відрізняється від пароля домашнього роутера.
4. Симулятор та технічні подробиці сховані в «Додатково». Системні порти на зразок Bluetooth COM3 за замовчуванням не показуються; повний список доступний у ручному виборі USB-порту. На Linux збережено повний список портів, оскільки Windows USB registry там недоступний.

## Керування без браузера

Після підтвердженого підключення S3 0.3 натиснути **«Тест GPIO14 · Wi-Fi»** у вкладці «Експеримент» або **«Керування GPIO14 та оновлення»** у вкладці «Підключення».

Відкриється окреме вікно самої програми. Пароль, прочитаний через USB у цьому сеансі, підставляється автоматично; для запуску програми лише через Wi-Fi його можна ввести вручну. Пароль нового вікна не записується на диск.

- «Підключитися» читає стан, не запускає мотор.
- «Підготувати тест» запускає сесію з нульовим газом.
- Ввести газ 0–10% з кроком 0,1% та натиснути «Задати газ».
- STOP відправляє зупинку і перевіряє нульовий вихід у відповіді плати.
- Закриття вікна припиняє heartbeat і намагається надіслати Stop. При втраті команд працює наявний таймер плати 1 с; повторного автоматичного запуску немає. Максимум сесії — 30 с.
- У розділі «Оновлення прошивки через Wi-Fi» можна обрати `.ptfw` через звичайне вікно вибору файла. Програма передає пакет, чекає інший завантажений розділ та підтверджує запуск. Підтримується перевірений API S3-Connect 0.3.x; несумісна нова версія не підтверджується.

Це окрема перевірка моторного виходу, не запис вимірів тяги. Датчики S3 ще не інтегровані. Обмеження і схема GPIO14 описані в [S3-OTA.md](S3-OTA.md).

## Перевірка цього випуску

58 автоматичних тестів пройшли без помилок. Нові тести перевіряють відхилення невідповідного GPIO/API, відсутність запуску при читанні стану та Stop під час затриманої відповіді на arm — через імітований HTTP-пристрій, без фізичного запуску.

Візуально переглянуто знімки Avalonia для головного вікна 1220×850 і 960×680 та вікна керування 660×700. Дві візуальні ітерації, оцінка 9/10; суттєвих перекриттів не виявлено. На меншій висоті налаштування прокручуються.

У цьому випуску мотор не запускався й OTA на фізичну плату не виконувалося. Попередня перевірка OTA прошивки та повідомлення користувача про успішний GPIO14-тест не замінюють фізичної перевірки нового desktop-керування. Не змінювалися прошивка, GPIO, ліміти, архів та код Uno.
