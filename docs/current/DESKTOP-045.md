# Desktop 0.4.5 — компактні стрілки напрямку

Дуги зменшені з радіуса 99 до 72 умовних одиниць, довжина — з 75° до 45°. Вони стоять у проміжках між лопатями, дзеркально для кожного мотора. Стрілки декоративні, без реакції на наведення. Напрямки схематичні. Прошивку та керування ESC не змінено.

Запуск: START-v2.cmd після збирання scripts/build.ps1 -Publish. Пакет: artifacts/windows-v2-desktop-045. Початкові скетчі та бібліотеки GitHub збережені.

Переглянуто рендер 960×680: сусідні дуги не перетинаються, підписи не перекриті. Візуальна оцінка 9/10 після однієї ітерації. Дуги можуть проходити поверх променів рами; при анімації вони залишаються нерухомими. Фізичне обладнання не тестувалося.

Повний набір тестів: 64/64 пройшли. У старому UI-тесті підказки виправлено синхронізацію малювання перед перевіркою її меж.
