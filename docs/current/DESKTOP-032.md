# Desktop 0.3.2 — збережені плати

Запуск: `START-v2.cmd` або `artifacts/windows-v2-desktop-032/PropTest.Desktop.exe`. Для перенесення потрібна вся папка збірки. Прошивка залишається S3-Connect 0.3.0; оновлювати її для цієї зміни не потрібно.

## Використання

1. Нову плату один раз підключіть через USB. Після підтвердження S3-Connect програма запам’ятає її постійне ім’я та ключ доступу. Wi-Fi роутера налаштовується окремо через USB, як раніше.
2. У «Підключення → Wi-Fi» виберіть плату зі списку «Мої плати». Можна змінити назву та натиснути «Зберегти назву». Це назва на цьому комп’ютері, а не зміна імені прошивки.
3. Увімкніть «Підключатися автоматично». Плата та комп’ютер мають бути в одній локальній мережі. Програма використовує `proptest-v2-xxxxxx.local`, тому зміна IP роутером не потребує повторного введення адреси.
4. «Відключити» призупиняє автопідключення до кінця поточного запуску програми. Відновити його можна ручним підключенням, вибором іншої плати або вимкненням і повторним увімкненням галочки.

Автоматично підключається лише вибрана плата. Невідомі плати автоматично не додаються. Якщо плата недоступна, фоновий запит раз на 5 секунд не блокує інтерфейс і не відкриває вікно помилки. Виявлення — тільки запит стану; мотор автоматично не запускається. Після підключення тест GPIO14 відкривається у програмі, підготовка і газ задаються вручну.

## Збереження та доступ

Профілі: `%LOCALAPPDATA%/PropTestEngineering/boards-v1.json`, поруч із базою вимірів. Ключ доступу зберігається через Windows DPAPI для поточного облікового запису. Він не записується відкритим текстом. Повторне введення пароля не потрібне, але автентифікація плати збережена. Для іншого Windows-користувача або іншого комп’ютера потрібне повторне USB-підключення. Збереження ключів на Linux у цій версії не реалізовано; відкритого текстового запасного варіанта немає.

Файл із пошкодженими профілями не перезаписується мовчки: програма повідомляє його розташування. Історичний IP зберігається довідково; автоматичне підключення використовує постійне ім’я. Мережа має пропускати mDNS; ізоляція Wi-Fi-клієнтів або блокування локального виявлення можуть завадити підключенню.

## Перевірка

Перевіряються збереження кількох плат, захист ключа, перейменування, ручне від’єднання, недоступність плати без блокування UI та збереження вибору в списку. Перевірка фізичної плати в тестах вмикається лише явно через `PROPTEST_VERIFY_SAVED_BOARD=1`; без цього обладнання не використовується. Вона не запускає мотор. Моторні обмеження та OTA не змінені.

Результат 2026-10-01: збірка та публікація Windows x64 успішні; 62 тести пройшли. Явно ввімкнена перевірка збереженої фізичної плати підтвердила автопідключення через `proptest-v2-858428.local` і ручне від’єднання. Додатково `/status` підтвердив S3-Connect 0.3.0, GPIO14, armed=false, target=0, applied=0. Мотор не запускався, прошивка не змінювалася. Зміну IP примусово не відтворювали. UI переглянуто на 1220×850 та 960×680: 9/10 після двох візуальних ітерацій; на малому вікні нижні налаштування доступні прокручуванням.
