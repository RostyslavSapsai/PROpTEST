# Desktop 0.4.6 — діапазон часу

Поля «Від, с» і «До, с» згруповані в окрему картку «Діапазон часу». «Застосувати» встановлює діапазон для всіх графіків відповідного блоку. «Скинути» повертає автоматичний масштаб усього запису, скидає помилку введення та відновлює врахування нових вимірів. Окрема кнопка «Авто» у вікні одного графіка прибрана як дубль.

Компактне вікно має мінімальну висоту 520: при ширині 480 кнопки переносяться на другий рядок, графік залишається видимим.

Цільові тести графіків та огляду моторів пройшли; перевірено скидання через кнопку й розширення діапазону при надходженні нового виміру. Переглянуто компактний графік, вузьке вікно та всі графіки мотора. Візуально 9/10 після двох ітерацій. На вузькому вікні кнопки займають другий рядок. Обладнання не запускали.

Запуск: START-v2.cmd або artifacts/windows-v2-desktop-046/PropTest.Desktop.exe.
