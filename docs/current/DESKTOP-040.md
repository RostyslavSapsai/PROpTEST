# Desktop 0.4.0 — огляд чотирьох моторів

Запуск: START-v2.cmd або artifacts/windows-v2-desktop-040/PropTest.Desktop.exe. Для перенесення потрібна вся папка збірки.

На головному екрані — сіра схема квадрокоптера з трилопатевими пропелерами та позиціями M1–M4. При наведенні мотор підсвічується синім, курсор змінюється на руку. Натискання на мотор або заголовок картки відкриває всі його наявні графіки. Натискання на показник відкриває компактний графік з можливістю розгортання. Старі одномоторні графіки доступні у згорнутому розділі.

Поточні обмеження: це інтерфейс для майбутніх чотирьох каналів, а не завершена інтеграція чотирьох моторів. Прошивка S3-Connect 0.3.0 не передає датчики й підтримує лише окремий тест GPIO14. Legacy/симулятор має один потік вимірів, який показується лише на M1; M2–M4 не отримують копії цих даних. Температура та RPM позначені відсутніми, натискання пояснює їхню неготовність. Загальний струм чотириканального ESC не видається за струм кожного мотора. Наявність мотора залишається невизначеною; дані каналу не доводять фізичного підключення мотора. Пропелери не анімовані, щоб не імітувати виміряні оберти.

Автовизначення потребує наступного окремого етапу: узгоджені чотири виходи ESC, протокол з ідентифікатором каналу та RPM/сумісна телеметрія або перевірені окремі датчики. Нульова тяга не означає відсутній мотор. Автоматичний пробний запуск при підключенні не додано. Прошивку й обладнання цією зміною не змінювали.

Перевірка: попередній повний прогін — 64 тести пройшли. Після зміни малюнка на перенесеному середовищі повторно пройдено цільовий UI-тест: розділення каналів, живе оновлення вікон, курсор при наведенні та його скидання. Знімки огляду на 1220×850 і 960×680, компактного та повного вікон сформовані. Переглянуто нову схему й синє підсвічування: 9/10, одна візуальна ітерація цього уточнення. На малому вікні нижні показники потребують прокручування. Перевірки на фізичній платі й запуску мотора не було.
