# Desktop 0.4.1 — FPV-силует і компактні показники

Запуск: START-v2.cmd або artifacts/windows-v2-desktop-041/PropTest.Desktop.exe. Переносьте всю папку збірки.

За ескізом користувача збільшено центральну чорно-сіру векторну модель: довгі промені, вузька рама, камера, моторні маточини й профільовані трилопатеві пропелери. Кіл вибору немає. Синій контур проходить по лопатях та маточині. Перевірка наведення використовує геометрію лопатей, а не круглу область; порожній простір між ними не є кнопкою.

Показники кожного мотора розкладені компактними плитками 2×3. Натискання на плитку відкриває графік; натискання на мотор — усі його графіки. Наявні обмеження 0.4.0 щодо даних, RPM, температури й автовизначення залишаються чинними. Колір наведення не означає виявлений мотор.

Перевірено збирання, UI-тест живих графіків/ізоляції каналів/наведення та скриншоти 1220×850 і 960×680. Візуально 9/10 після двох ітерацій: прибрано обрізаний підпис температури, зменшено плитки, щоб усі значення вміщувалися на мінімальному вікні. Нижня довідка й старі графіки доступні прокручуванням. Фізичне обладнання не тестувалося; прошивку й керування мотором не змінювали.
