# Desktop 0.4.4 — дугові стрілки обертання

Запуск: START-v2.cmd або artifacts/windows-v2-desktop-044/PropTest.Desktop.exe.

Замість маленьких символів біля M1–M4 намальовано три тонкі дугові стрілки навколо кожного пропелера за ескізом користувача. M1/M4 — зеленуваті за годинниковою стрілкою; M2/M3 — червонуваті проти. Підписи винесені за дуги. Напрямки залишаються схематичними; керування ESC та анімація не змінені.

Перевірено: цільовий UI-тест 1/1 пройшов, переглянуто рендер 960×680. Візуальна оцінка 9/10 після однієї ітерації: дуги рівні та тонкі, кольори приглушені порівняно з ескізом. Фізичні напрямки обертання не перевірялися.
