# Desktop 0.3.5 — доступні та збережені плати

Запуск: START-v2.cmd або artifacts/windows-v2-desktop-035/PropTest.Desktop.exe. Переносьте всю папку збірки.

Над компактною плашкою додано «Вибір пристрою». Основний список показує лише плати, доступність яких підтверджено, та активне з’єднання. Якщо таких немає, видно повідомлення про відсутність пристроїв; перевірка продовжується, поки панель відкрита. Знизу текстова кнопка «Збережені мережі» відкриває всі запам’ятовані плати. Повернення — «Доступні пристрої».

Галочка автопідключення, перейменування і кнопка підключення/від’єднання розкриваються лише після натискання на назву плати всередині списку. Повторне натискання згортає їх. Розкриття основної плашки саме по собі не розкриває кнопки плати.

Пошук як і раніше перевіряє відомі плати; нова плата додається через USB. Зникнення зі списку після втрати мережі відбувається після чергової перевірки доступності, не миттєво. Моторні функції та прошивка не змінювалися.

Перевірка: 63 тести пройшли. Новий UI-тест перевіряє порожній список, окреме відображення збережених плат, появу/зникнення пристрою при зміні доступності та розкриття/згортання кнопок натисканням. Мережеві стани в цьому тесті змодельовані; фізичну плату цього разу не тестували. Візуальна оцінка 9/10 після однієї ітерації: переглянуто порожній список і розгорнуту картку. На малих вікнах залишається прокручування вкладки.
