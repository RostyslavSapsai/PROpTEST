# PROpTEST v2 — S3-Connect 0.2.0

Це перший етап другого покоління: з’єднання з ESP32-S3 через USB або Wi-Fi.
Прошивка Arduino Uno PT:2.2 зберігається окремо і підтримується програмою.

## Що працює у цій версії

- Виявлення USB Espressif та поширених USB-UART мостів у Windows. USB ID — лише підказка; готовність підтверджується відповіддю прошивки.
- Окреме ім’я прошивки `S3-Connect 0.1.0`, протокол `PT:S3:0.1`.
- Власна Wi-Fi мережа плати `PROpTEST-v2-XXXXXX`, WPA2, випадковий пароль на кожну плату, збережений у NVS.
- USB і TCP використовують однакові команди перевірки зв’язку.
- Перевірка відповіді кожні 750 мс; після 3,5 с без відповіді програма повідомляє про втрату зв’язку.
- У програмі 0.1.1 Wi-Fi підключається лише кнопкою «Перевірити з’єднання». Повторні спроби кожні 5 секунд прибрано. Після успішного підключення залишається фонова перевірка живого зв’язку без повторного відкриття з’єднання та блокування кнопок.

## Як користуватись без втрати інтернету

1. Запустити `START-v2.cmd` і підключити плату USB-кабелем.
2. Відкрити «Підключення» → «Wi-Fi через роутер — зі збереженням інтернету».
3. Ввести SSID мережі 2,4 ГГц та пароль WPA2 (8–63 ASCII-символи), натиснути «Зберегти мережу на платі». Пароль очищається з поля після надсилання, не записується в журнали чи файли програми; на платі зберігається в NVS без шифрування flash.
4. Дочекатися статусу «Плата в мережі роутера» та IP-адреси. Програма підставляє цю адресу для Wi-Fi підключення.
5. Натиснути «Відключити», вибрати Wi-Fi і «Перевірити з’єднання». Ноутбук залишається у звичайній мережі з інтернетом. Після налаштування ESP32 можна живити від павербанка.

Ноутбук може працювати на 5 ГГц того самого роутера. ESP32-S3 потрібні 2,4 ГГц. Роутер має дозволяти обмін між клієнтами (гостьова мережа або client isolation можуть його забороняти). Точка доступу телефона також підходить, якщо підтримує 2,4 ГГц та зв’язок між клієнтами.

При зміні IP його можна прочитати через USB або використати ім’я плати `proptest-v2-XXXXXX.local`, якщо мережа та ОС підтримують mDNS. Адреса Wi-Fi поки не зберігається програмою між запусками.

Власна мережа `PROpTEST-v2-XXXXXX` залишається запасним способом зв’язку: адреса `192.168.4.1`, TCP `8768`, інтернету вона не надає. Її пароль відрізняється від пароля роутера. Програма не перемикає мережі Windows автоматично і не повторює невдалі підключення кожні 5 с.

Запуск EXE: `artifacts/windows-v2-connect-021/PropTest.Desktop.exe`; переносити всю папку.

## Обмеження

**S3-Connect не керує ESC, не опитує датчики і не створює вимірювань.** GPIO датчиків/ESC не налаштовуються. «Почати тест» заблоковано як у UI, так і в контролері запуску. Команди запуску/газу прошивка відхиляє. Це перевірка зв’язку, не готова моторна прошивка.

Wi-Fi реалізація приймає один TCP-клієнт. Пароль передається лише фізичним USB/UART каналом, не через TCP. Перед майбутнім додаванням моторів потрібно окремо реалізувати та фізично перевірити watchdog, аварійну зупинку та право керування; поточний heartbeat слугує лише індикації зв’язку.

## Протокол

115200, 8N1, LF. Команда до 96 символів, переповнення відкидається до наступного LF.

| Команда | Відповідь |
|---|---|
| `P` | `PT:S3:0.1` |
| `I` | `INFO\|PROpTEST v2\|S3-Connect 0.1.0\|NO_SENSORS\|NO_MOTOR\|ssid\|ip\|port` |
| `I` через USB/UART | Додатково `WIFIKEY\|password` |
| `H` | `PONG` |
| `G` | `ACK:G:0` (виходи моторів не активуються) |
| Інші | `ERR:CONNECTION_ONLY` |

## Збирання

Arduino ESP32 core **3.3.12**. Профіль `esp32:esp32:esp32s3:CDCOnBoot=cdc,USBMode=hwcdc,FlashSize=16M,PSRAM=disabled`.
PSRAM поки не використовується; на платі інструментом Espressif виявлено 16 МБ flash і 8 МБ PSRAM.
Файли прошивки: `firmware/PropTestS3/PropTestS3.ino`. Команди — `scripts/build-s3.ps1`.

Після першого переходу BOOT + RESET номер COM може змінитися — це нормально. Другий USB-UART роз’єм підтримується через UART0; фізична перевірка потрібна окремо від перевірки native USB.

Офіційні джерела: [USB CDC](https://docs.espressif.com/projects/arduino-esp32/en/latest/tutorials/cdc_dfu_flash.html), [Wi-Fi AP](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/wifi.html).

## Перевірка станом на 2026-09-29

- Прошивка скомпільована core 3.3.12 та записана через COM7; esptool підтвердив хеш записаних даних.
- Повна резервна копія попередньої flash: `artifacts/hardware-diagnostics/s3-before-20260929.bin`, 16 777 216 байтів. SHA256: `CD0F30AC9491DA499EAF2167F07B5ACCF23CF6779C506110431AA766F346273E`.
- 51 автоматизована перевірка без фізичної плати пройшла. Окремий opt-in тест реальної S3 запускається лише зі змінною `PROPTEST_S3_PORT`; без неї він не виконує апаратних перевірок.
- Реальна плата після першої прошивки поки не відповіла на `P`; потрібне ручне натискання RESET без BOOT. Успішне USB-підключення, робота Wi-Fi по радіоканалу та другий USB-роз’єм **ще не підтверджені**.
- Вкладка підключення перевірена на зображенні Avalonia: дві ітерації, оцінка 9/10; це не перевірка підключеного пристрою.
- Готовий автономний Windows-пакет: `artifacts/windows-v2-connect-021`. Комітів та push не виконано.

## Оновлення програми 0.1.1

Пароль — випадковий 16-символьний ключ мережі плати, створений прошивкою 0.1.0 та збережений у NVS. Його можна прочитати через USB і скопіювати окремою кнопкою. Прошивка та пароль цим оновленням не змінюються. Реальну плату під час цього оновлення Windows не показувала серед USB-портів, тому апаратна перевірка не виконувалась.

## Оновлення 0.2.0 — 2026-09-30

- Прошивка `PT:S3:0.2`: режим AP+STA, налаштування роутера через USB, збереження мережі, mDNS, статус підключення через `NETWORK|state|ip|hostname`.
- `NET:<SSID у hex UTF-8>:<пароль у hex ASCII>` дозволений тільки через USB/UART. Hex — лише кодування, не шифрування. Максимум команди 200 символів. Мережевий клієнт не може змінювати ці налаштування.
- Налаштування передаються без очікування підключення в UI; результат читається через фонові відповіді плати. AP залишається доступною при неправильному паролі роутера.
- Другий USB-роз’єм з CH343 (VID 1A86 / PID 55D3, COM8 під час перевірки) доданий до автовиявлення. Не покладатися на номер COM як постійний.
- Firmware зібрана Arduino ESP32 3.3.12, записана на фізичну плату з перевіркою хешу. 10 цільових тестів пройшли, зокрема реальне USB-автовиявлення, heartbeat, ручне відключення та повторне підключення.
- GPIO20 зайнятий USB D+; його не можна призначати ESC у цій конфігурації. Моторне керування у прошивці відсутнє.
- Перевірка Wi-Fi через роутер очікує введення користувачем даних мережі. Сам факт компіляції або USB-зв’язку не підтверджує роботу радіоканалу.

## Оновлення програми 0.2.1 — 2026-09-30

Прошивка залишається 0.2.0. Додані показ/приховування пароля, виділення інформаційного тексту у вкладці підключення, копіювання IP та окреме немодальне вікно після збереження мережі. Вікно відразу показує хід підключення і оновлюється разом зі статусом; закриття вікна не скасовує підключення.

Підтверджено TCP-зв’язок із фізичною платою через роутер (відповідь PT:S3:0.2). Домашня Wi-Fi мережа ноутбука не перемикалась. 10 цільових тестів пройшли, включно з реальним USB-зв’язком. Вікно результату візуально перевірене на реальних даних плати. Копіювання в буфер ОС реалізоване; автоматизованого тесту системного буфера обміну не виконували.
