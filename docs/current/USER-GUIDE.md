# Інструкція користувача — Engineering v0.14

[Зміст](README.md)

## Запуск

У повній локальній папці Engineering запустіть `START.cmd` або `artifacts/windows-v14/PropTest.Desktop.exe`. Для перенесення потрібна **вся папка windows-v14**. Збірка самодостатня для Windows x64; окреме встановлення .NET для неї не потрібне.

Ця публікація документації не містить EXE або нового публічного релізу. Історичний GitHub checkout не має START.cmd актуальної програми.

## Ознайомлення без мотора

Для огляду інтерфейсу виберіть симулятор у вкладці «Підключення». Дані цього режиму синтетичні; вони не є результатами фізичного експерименту. Реальний режим без підключеного пристрою не повинен генерувати тягу. Нулі на інформаційній панелі при відключенні не означають виконаний вимір.

## Підключення реального стенда

1. Переконайтеся, що використовується перевірена схема поточного Uno-стенда. Перша перевірка нового обладнання проводиться без пропелера й без подавання ненульового газу.
2. Підключіть USB. Закрийте Serial Monitor або інші програми, які займають порт.
3. У вкладці «Підключення» вимкніть симулятор, виберіть COM і підключіться. Частина Arduino-пристроїв визначається автоматично.
4. Дочекайтеся підтвердження протоколу. Номер COM може змінюватися; COM5 не є обов'язковим.
5. До навантаженого тесту перевірте кріплення, допустимі струми та можливість незалежно від ПК відключити силове живлення.

Підключення до USB саме по собі не запускає мотор. Запуск тесту PT:2.2 починає сесію з нульовим газом. Процедура живлення/армінгу конкретного ESC має відповідати його документації.

## Експеримент

Задайте назву, інтервал вимірів, тривалість і ліміт газу. У моделі допустимі інтервали 50–2000 мс і тривалість 1–7200 с; це межі налаштувань, а не підтвердження точного семплювання або двогодинної витривалості.

Натисніть «Почати тест». Змінюйте газ повзунком або числом. Верх повзунка відповідає увімкненому ліміту. Кнопка 6% явно задає 6% — це спостережений поріг запуску на цьому моторі, не універсальне значення.

Поточна прошивка Uno має власну стелю 30%, незалежну від максимального значення UI. Відсотки не є обмеженням струму чи потужності для довільного акумулятора.

Для штатної зупинки натисніть STOP. Підтвердження команди означає стан керування, а не виміряну механічну зупинку ротора.

## Графіки

| Дія | Керування |
|---|---|
| Вибрати часову ділянку | Перетягування лівою кнопкою |
| Пересунути ділянку | Перетягування правою кнопкою |
| Масштабувати | Ctrl + коліщатко |
| Повернути попередній масштаб | Ctrl+Z у графіку |
| Показати весь запис | «Авто» |
| Задати точний інтервал | Поля «Від, с», «До, с», «Показати» |
| Окреме вікно | «Окремо» |
| Прокрутити сторінку | Коліщатко без Ctrl |

Послідовні рухи коліщатка з паузами менше 0,5 с групуються в одну дію скасування. Часовий діапазон графіка не змінює тривалість експерименту. Підказка точки показує конкретний запис; збільшення графіка не створює нових вимірів.

## Архів і CSV

У вкладці «Архів» виберіть тест і натисніть «Експорт CSV». Очікувана поведінка v0.14: системне «Зберегти як», запропонована назва `PROpTEST_<назва>_<дата-час>.csv`, вибір папки та підтвердження перезапису. Скасування не створює файл. Нативний діалог Windows ще потребує ручної перевірки, хоча логіка експорту має програмні перевірки.

База: `%LOCALAPPDATA%/PropTestEngineering/runs-v1.db`. Закрийте програму перед резервним копіюванням. Старі записи не перераховуються автоматично за новими калібруваннями; при порівнянні враховуйте поле джерела, версію прошивки й одиниці.

## Типові проблеми

| Симптом | Що перевірити |
|---|---|
| COM видно, але немає відповіді | Правильний порт, 115200 бод, версію прошивки, завершення її запуску, зайнятість порту |
| Автопідключення не спрацювало | Спробувати ручний вибір; інші USB VID не означають поломку плати |
| Мотор не стартує на малому газі | Поріг мотор/ESC; не приховувати його перерахунком шкали й не піднімати газ без контролю навантаження |
| Від'ємна або нестабільна тяга | Напрямок сили, кріплення, нуль, калібрування; не брати модуль усіх показів |
| Низькі числа звуку | Це ADC, а не dB SPL; не додавати штучний мінімум 40 дБ |
| XYZ близькі до ±1 g | Може бути проєкція гравітації; перевірити орієнтацію й методику |
| Експорт не завершився | Вибір тесту, права на папку, повідомлення з технічними деталями |
