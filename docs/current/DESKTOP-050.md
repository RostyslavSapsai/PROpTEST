# Desktop 0.5.0 · чотири мотори · S3-Connect 0.4.0

## Керування

Натисніть мотор на схемі або заголовок його картки. Відкриється єдине вікно керування з вибором M1–M4, окремими значеннями газу та лімітами. Кнопка «Графіки» відкриває показники; нижні графіки збережені.

1. Підключіть плату до програми та відкрийте керування мотором.
2. Перед першою перевіркою зніміть пропелери. Розпіновку штатного ESC звірте окремо: номери нижче — GPIO ESP32, не позиції у штекері.
3. За потреби встановіть прошивку `PROpTEST-S3-0.4.0.ptfw` через секцію оновлення. Під час оновлення силове живлення ESC має бути відключене. Безпечно перевірте нові виходи до моторного тесту. Автоматичне прошивання в цій зміні не виконувалось.
4. Встановіть індивідуальні ліміти 0–10% до підготовки тесту, потім натисніть «Підготувати тест». Газ усіх моторів залишиться нульовим.
5. Виберіть мотор, задайте газ повзунком або числом і натисніть «Задати газ». Перехід до іншого мотора не змінює вже застосовані команди.
6. «Зупинити цей мотор» задає нуль тільки вибраному каналу. «STOP · усі мотори» зупиняє всю сесію. Закриття вікна також надсилає загальний Stop.

Ліміти й незастосовані значення зберігаються лише у відкритому вікні. Зміна ліміту під час підготовленої сесії заблокована. Нове підключення не запускає мотор. Одночасно працює одне вікно керування для цієї програми.

## Сигнали

| Мотор | GPIO ESP32-S3 |
|---|---|
| M1 | 10 |
| M2 | 11 |
| M3 | 12 |
| M4 | 13 |

Це призначення зі збереженої схеми `artifacts/wiring-v2/index.html`. GPIO14 більше не налаштовується. Сигнали M1–M4 ESC та спільний GND необхідно звірити на конкретній ревізії ESC; VBAT не підключати до GPIO. Реалізований PWM 50 Гц, імпульси 1000–1100 мкс для обмеженого тесту 0–10%; це не DShot. Сумісність і фактичний газ ESC потребують фізичної перевірки.

## Протокол та зупинка

- Ідентифікатор USB/TCP: `PT:S3:0.4`. HTTP status: `S3-Connect 0.4.0`, `motors` містить чотири елементи `pin/target/applied`.
- POST `/gas`: `token`, обов'язковий `motor` 1–4, `value` 0–100 (десяті частки відсотка). Команда змінює один канал. Невірний номер/газ припиняє всю сесію.
- Спільна сесія до 30 с; без lease/команд 1000 мс — нуль і роззброєння всіх каналів. Нуль задається без плавного зниження; ненульові зміни мають крок 0,1% за 20 мс.
- STOP перевіряє нуль усіх `target/applied` після свіжого циклу завдання. Це програмне підтвердження виходів, не вимір фізичної зупинки ротора.
- Помилка PWM вимикає всі чотири виходи. Оновлення можливе лише зі зупиненими виходами. Watchdog та OTA rollback збережені.
- Стару прошивку 0.3 можна прочитати й оновити, але новий екран M1–M4 не дозволяє запуск її GPIO14.
- Вбудована браузерна сторінка тепер лише вказує користуватися настільною програмою, щоб не пропонувати застаріле керування GPIO14.

## Інтерфейс графіків

Вибір моторів доступний в обох режимах; «Усі» та «Скинути» згруповані. Є вибір/приховування всіх каналів мотора, кольорові заголовки окремих графіків, кнопки інформації. Діапазон часу оновлюється через 300 мс або Enter; помилки з'являються лише для некоректного вводу.

## Перевірки й межі

70 автоматичних тестів пройшли, включно з незалежними командами M1/M3, окремою та загальною зупинкою, перевіркою чотирьох GPIO, блокуванням старого GPIO14 та handshake 0.4. Після корекції компонування повторно пройшли 5 тестів керування. UI перевірено на рендерах 660×780, 500×550 та основного вікна 960×680; візуально 9/10 після двох ітерацій. На мінімальній висоті потрібне прокручування; загальний STOP залишається видимим.

Arduino ESP32 3.3.12: прошивка зібрана в `artifacts/firmware-s3-040`, OTA-пакет створено. Фізичну плату не прошивали, мотори не запускали, осцилографом сигнали та час зупинки не перевіряли. Датчики ESP32 ще не активовані; керування не додає реального запису чотириканальних вимірів.

Збірка: `scripts/build.ps1 -Publish`; прошивка без завантаження: `scripts/build-s3.ps1`. Запуск: `START-v2.cmd`. Пакет програми: `artifacts/windows-v2-desktop-050`.
