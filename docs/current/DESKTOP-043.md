# Desktop 0.4.3 — масштабування та анімація пропелерів

Запуск: START-v2.cmd або artifacts/windows-v2-desktop-043/PropTest.Desktop.exe. Переносьте всю папку збірки.

Ctrl + прокручування миші чи двома пальцями touchpad змінює масштаб графіка. Дробові кроки підтримуються. Ctrl+Z скасовує серію прокручувань. Додано обробник щипка: один жест — одна дія скасування. Обробник працює, якщо ОС/драйвер передає відповідні події; підтримку конкретного фізичного touchpad не перевірено. Основа: https://v11.docs.avaloniaui.net/docs/reference/gestures/pinchgesturerecognizer/

Дубльовані кнопки «Розгорнути» прибрані з окремих вікон графіків. Залишається системне розгортання вікна Windows.

Біля M1–M4 додані стрілки: M1/M4 за годинниковою, M2/M3 проти. Це умовна схема, а не прочитаний напрямок ESC. Анімація плавно змінює швидкість і видимість лопатей до напівпрозорого диска за прикладеним газом поточного запису. Вона не вимірює RPM та не підтверджує обертання. Для поточного одиночного потоку анімується лише M1. За відсутності власних даних M2–M4 нерухомі; після завершення тесту анімація зупиняється. При закритті контрола таймер зупиняється. Команди керування обладнанням не змінені.

Перевірено: 7 UI-тестів після основних змін; потім 2 цільові тести з доданими перевірками дробових подій прокручування, щипка та скасування; повторний тест огляду після корекції позиції підписів. Усі пройшли. Переглянуті рендери 960×680, 1220×850, рух M1 і компактний графік. Оцінка 9/10 після двох візуальних ітерацій; розмиття стилізоване. Реальний touchpad, системне оформлення вікна і фізичний мотор не перевірялися.
