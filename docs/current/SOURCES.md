## Готове формулювання для сайту

> PROpTEST — прототип стенда та Windows-програми для дослідження моторно-пропелерних комбінацій. Поточна версія керує одним мотором через USB, записує тягу, струм, прискорення XYZ та відносний звуковий сигнал і дозволяє аналізувати графіки та експортувати CSV. Наступна апаратна версія розробляється для Wi-Fi, вимірювання напруги й розширення до чотирьох моторних каналів.
