# Desktop 0.3.3 — простіше підключення

Запуск: START-v2.cmd або artifacts/windows-v2-desktop-033/PropTest.Desktop.exe. Переносьте всю папку збірки. Прошивка S3-Connect 0.3.0 залишається без змін.

- Кругла кнопка i відкриває покрокову інструкцію першого USB-підключення, налаштування роутера та наступних Wi-Fi-підключень.
- Збережені плати показуються списком. Список доступний під час підключення; іншу плату можна вибрати, не розриваючи поточний зв’язок. Кнопка «Підключити» закриває старе з’єднання та відкриває нове. Поточна підключена плата підписана окремо.
- Автопідключення зберігається для кожної плати; при запуску використовується остання вибрана плата. Сам вибір іншої плати не перемикає з’єднання без натискання «Підключити».
- «Відключити» зберігає плату в списку і призупиняє автопідключення на поточний запуск. Відновлення — ручне підключення або повторне ввімкнення галочки.
- «Змінити назву…» відкриває окреме вікно. Назва локальна для комп’ютера.
- Адреси, прямий Wi-Fi плати та сервісне оновлення сховано в «Додатково». Керування мотором лишилося на вкладці «Експеримент»; GPIO14 не винесено в назву основної кнопки. Моторний режим усе ще тестовий, інтеграції датчиків S3 ця версія не додає.

Список містить запам’ятовані плати, а не результати пошуку всіх пристроїв поблизу. Нову плату додавайте через USB. Механізм захищеного збереження ключа та постійного мережевого імені описаний у DESKTOP-032.md.

Перевірка 2026-10-01: 62 тести пройшли перед заключною правкою іконки; після неї 4 тести профілів/UI пройшли, включно з явно ввімкненою перевіркою фізичної плати. Перевірено вибір іншого, недоступного профілю під час активного Wi-Fi-з’єднання, закриття старого з’єднання, повідомлення про невдале підключення і повернення до справжньої плати. Двох фізичних плат немає, тому успішне перемикання між двома реальними платами не перевірене. Мотор не запускався. UI переглянуто на 1220×850 і 960×680, інструкцію — окремо; 9/10 після двох візуальних ітерацій. У малому вікні потрібне прокручування нижніх налаштувань.
