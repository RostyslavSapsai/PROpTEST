# Desktop 0.4.9 — спільні виміри й графіки під схемою

- Схема має максимальну ширину 1400, картки моторів масштабуються від 160 до 240 разом зі своїми кнопками й текстом. На мінімальному вікні видно всі чотири картки.
- Під дроном розміщено спільний графік із вибором M1–M4, кольоровою легендою, перемикачем окремих графіків та діапазоном часу. Окремі вікна збережені.
- Струм і звук показано як загальні показники стенда. Вони не дублюються біля кожного мотора та не зникають при знятті вибору M1. У режимі окремих графіків також є спільна група струму й звуку.
- Картки моторів містять тягу, вібрацію, температуру та оберти. Дані температури та RPM ще не надходять. Напруга має позначку «Немає даних».
- Початковий одномоторний інтерфейс перенесено на вкладку «Додатково».

## Межі вимірювання

Наявний протокол передає один потік; його тяга та вібрація відображаються тільки на M1. Інші мотори не отримують копій цих даних. Загальна тяга не обчислюється без повного набору незалежних вимірів. Прискорення різних датчиків не підсумовуються як «загальна вібрація». Звук ADC не є каліброваним рівнем шуму в дБ.

Для прототипу рекомендовано один датчик загального струму перед ESC та один мікрофон. Чотири зовнішні датчики перед спільним входом ESC 4-в-1 не дадуть окремого струму моторів. Для цього потрібні незалежні вимірювальні канали або відповідна телеметрія ESC.

[BrotherHobby 55A V1](https://www.brotherhobbystore.com/products/3-6s-8bit-55a4in1-esc-v1) заявляє Current meter: Yes. Це не підтверджує сумісність виходу CURRENT з ESP32: перед підключенням потрібні схема конкретної ревізії, діапазон напруги та коефіцієнт перерахунку. Підключення CURRENT не змінено.

## Перевірка

65/65 автоматичних тестів пройшли. Перевірено рендери 1920×1080, 1220×850, 960×680 і вікна графіка 760×600; візуальна оцінка 9/10, одна ітерація огляду. Нижні графіки й довга легенда прокручуються. Тести використовують синтетичні дані; фізичне обладнання не перевірялось, прошивка не змінювалася.

Запуск: START-v2.cmd або artifacts/windows-v2-desktop-049/PropTest.Desktop.exe. Для перенесення потрібна вся папка збірки.
