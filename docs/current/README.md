# PROpTEST — документація поточного етапу

Станом на **15 вересня 2026 року**. Мова документації — українська.

PROpTEST — випробувальний стенд і програмне забезпечення для дослідження комбінацій мотор, пропелер, ESC та акумулятор. Поточний стенд одномоторний; наступна апаратна версія передбачає Wi-Fi та розширення до чотирьох незалежних моторних каналів.

## Три різні позначення версій

| Позначення | Значення | Стан |
|---|---|---|
| PROpTEST Engineering v0.14 | Локальна Windows-програма C#/.NET/Avalonia | Реалізована; існує локальна збірка |
| PT:2.2 | Ідентифікація поточної прошивки Arduino Uno | Є вихідний код і попередні звіти апаратних перевірок |
| PROpTEST v2 | Наступне покоління обладнання на ESP32-S3 | Компоненти замовлені; інтеграція не виконана |

Публічний репозиторій містить історичні Arduino-скетчі. Цей пакет документує також окрему локальну програму Engineering: її код, EXE та прошивка PT:2.2 **не додаються цією публікацією**. Інструкції збирання застосовні до повного Engineering checkout, а не до історичних скетчів у корені GitHub.

## Як трактувати твердження

- **Реалізовано:** поведінка знайдена в поточному локальному коді.
- **Перевірено раніше:** є локальний звіт; це не повторна перевірка 15 вересня.
- **Повідомлено власником:** інформація з його спостережень, фотографій або замовлень.
- **Замовлено:** отримання, точна ревізія та працездатність ще не підтверджені.
- **Заплановано:** функція не є частиною поточної робочої версії.

Стенд є прототипом. Метрологічна точність, сертифікація та допустимі навантаження для довільних моторів не підтверджені. Симулятор і програмні тести не підтверджують фізичну безпеку.
