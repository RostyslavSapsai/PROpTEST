# PROpTEST Engineering — v2 · Desktop 0.4.5

Новий екран: схема чотирьох моторів із компактними графіками. Це підготовка інтерфейсу; чотириканальна телеметрія та автовизначення моторів ще не реалізовані.

Новий етап: [оновлення ESP32-S3 через Wi-Fi та тест GPIO14 до 10%](docs/current/S3-OTA.md). Датчики S3 ще не активовані. Тест GPIO14 та оновлення відкриваються у вікні програми; браузер не потрібний. Налаштування USB та Wi-Fi розділено. Плати зберігаються з власними назвами; є автопідключення за постійним мережевим ім’ям без повторного введення пароля. Див. [Desktop 0.4.5](docs/current/DESKTOP-045.md). Запуск: `START-v2.cmd`. Попередня Uno-версія: `START.cmd`.

Попередній пакет документації станом на 2026-09-15: [стан, інструкція, обладнання, протокол і план v2](docs/current/README.md). Компоненти v2 отримані. ESP32-S3 інтегрується окремим етапом зв’язку; моторна частина Uno залишається на PT:2.2.

## Збирання поточної версії

Потрібні Windows і .NET SDK 9.0.101 (див. `global.json`).

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Publish
```

Після збирання запустіть `START-v2.cmd`. Готовий пакет буде в `artifacts/windows-v2-desktop-045`; для перенесення потрібна вся папка.

Код програми: `src/`; тести: `tests/`; прошивки Uno й ESP32-S3: `firmware/`. Збирання програми не прошиває плату та не запускає мотор.

## Попередня Uno-версія

Запуск раніше підготовленого локального пакета: `START.cmd` або `artifacts/windows-v14/PropTest.Desktop.exe`.
Для перенесення потрібна вся папка `windows-v14`; окремий .NET не потрібний.

## Керування

- Чотири графіки: тяга, струм, прискорення XYZ, звук.
- Газ задається повзунком або числом з кроком 0,1%. Верх повзунка відповідає ліміту. Кнопка `6%` явно встановлює спостережений поріг запуску цього мотора; автоматичного перерахунку відсотків немає. Поріг іншої комбінації ESC/мотора може відрізнятися.
- Поля «Від, с» / «До, с» задають ділянку для чотирьох графіків; такі самі поля є в окремому вікні. Можна вказати майбутню межу, наприклад 120 с. Це перегляд, не зміна тривалості тесту.
- ЛКМ виділяє ділянку, ПКМ пересуває її, Ctrl + коліщатко змінює масштаб. Ctrl+Z на графіку повертає попередній масштаб; серія прокручувань із паузами менше 0,5 с скасовується однією дією; після «Показати» — повертає попередні діапазони групи. «Авто» показує весь запис. Звичайне коліщатко прокручує вікно.
- «Аварійна зупинка» зліва вмикається/вимикається до початку тесту. Типові пороги — 50 г і 30% від попередньої тяги, потрібне досягнення обох. Пороги налаштовуються. Два послідовні відхилення за сталого газу спричиняють Stop і збереження причини в архіві.
- Після зміни заданого або прикладеного газу контроль чекає 1,5 с та збирає щонайменше 3 опорні точки. Це контроль через ПК, а не незалежний апаратний захист. Деталі: `docs/controls-v10.md`.

## Показники

Звук у нових вимірах PT:2.x — амплітуда ADC. Для PT:2.1/2.2 це середній розмах повних 50-мс вікон. Штучний перерахунок `ADC × 120 / 1023` прибрано: він не вимірював децибели. Низький ADC не означає низький dB SPL. Для реального SPL потрібне акустичне калібрування/перевірка придатності мікрофона. Старі записи з dB* не переписуються.

Тяга має полярність −1 відповідно до підтвердженого напрямку цього стенда. Історичний коефіцієнт відновлено з flash; нової перевірки еталонним вантажем немає. XYZ: X вперед/назад, Y вверх/вниз, Z вправо/вліво; прискорення містить гравітацію, це не RMS вібрації. Струм — номінальна формула ACS712-20A, потребує калібрування. Напруга до Arduino не підключена; вати та Wh не вимірюються.

## Підключення та обмеження

| Канал | Контакти |
|---|---|
| ESC | D9, зараз 1000–1300 мкс |
| HX711 | DOUT D6, SCK D7 |
| ACS712 | A3 |
| Мікрофон | A0 |
| MMA8452Q | I2C A4/A5, адреса 0x1D |

Прошивка має незнімний через UI ліміт 30%, плавну зміну ненульового газу, Stop із підтвердженням та відключення за відсутності heartbeat понад 1 с. Відсічення при номінальній оцінці |I| ≥ 8 А не замінює електричний захист. Це не підтвердження безпечності всіх механічних конфігурацій.

Архів SQLite: `%LOCALAPPDATA%/PropTestEngineering/runs-v1.db`; експорт CSV у вкладці «Архів». Оберіть запис і натисніть «Експорт CSV»: відкриється «Зберегти як» із назвою тесту та датою у назві файла. Виберіть папку й натисніть «Зберегти». Симулятор вмикається окремо й позначає дані синтетичними.

## Розробка

`powershell -File scripts/build.ps1 -Publish` — збирання, тести, готова папка Windows. Прошивка збирається і завантажується окремо, див. `firmware/README.md`.

Прототип `D:\PT\PropTEST` не змінено. Резервні копії оригінальних flash/EEPROM залишені в `artifacts/hardware-diagnostics`. Поточні перевірки — `docs/STATUS.md`; попередні апаратні дослідження — `docs/hardware-v07.md`, `docs/sound-v09.md`.
